Per acquisire i dati del monitor seriale, apri un progetto su Tinkercad Circuits.

🚀 Apri Tinkercad Circuits
💡 Esempio Arduino per Excel/Scilab

Stampa i valori separati da virgola:

void loop() {
  int v1 = analogRead(A0);
  float v2 = v1 * (5.0 / 1023.0);
  Serial.print(millis());
  Serial.print(",");
  Serial.println(v2);
  delay(100);
}
  • Excel IT: Seleziona separatore ; e conversione decimale.
  • Scilab: Usa csvRead("file.csv", ",") per caricare la matrice!
